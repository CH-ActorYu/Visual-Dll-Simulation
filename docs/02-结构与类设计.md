# 02 — 项目结构与类设计

| 项目 | 内容 |
| --- | --- |
| 文档版本 | V1.0 |
| 对应需求 | [01-需求规格说明书](./01-需求规格说明书.md) V3.4（§4 解决方案结构） |
| 说明 | 各项目的类级划分：类名、对外方法、作用。本文档是编码的对照表，README/SRS 中只保留结构概述 |

约定：

- 模块/共享层仅 `Contracts`（接口 + DTO + 异常）对外可见，实现类一律 `internal`；
- 耗时操作一律异步：`Task` + `CancellationToken`；
- `Mat` 的生命周期遵循"谁创建谁释放"，跨层传递时由调用方负责释放。

---

## 1. Visual.Abstractions（基础契约）

跨模块通用类型。不含任何逻辑，只有数据与接口形状。

### 1.1 值对象

| 类 | 成员 | 作用 |
| --- | --- | --- |
| `FramePacket` | `Mat Frame`、`long FrameIndex`、`DateTime Timestamp`、`string? SourceId` | 一帧数据的统一载体，IO 产出、模块消费 |
| `RoiRect` | `X / Y / Width / Height`、`Area`、`ClampTo(int width, int height)`（越界收敛返回新实例）、`Contains(Point2D)` | 圈选区域，不可变值对象 |
| `Point2D` | `X / Y` | 像素坐标 |
| `DistanceUnit`（枚举） | `Mm / Cm / M` | 距离单位 |

### 1.2 结果基类

| 类 | 成员 | 作用 |
| --- | --- | --- |
| `VisionResultBase` | `Confidence`、`Timestamp`、`FrameIndex`、`SourceId` | 各模块结果 DTO 的共同基类 |

### 1.3 异常

| 类 | 成员 | 作用 |
| --- | --- | --- |
| `VisionException` | `VisionErrorCode ErrorCode` | 所有模块异常的基类，屏蔽第三方异常 |
| `VisionErrorCode`（枚举） | `InvalidInput / NotRunning / DeviceLost / DecodingFailed / ModuleSpecific(int 起点)` | 错误码；模块自定义码从 ModuleSpecific 起编 |

### 1.4 模块入口

| 接口 | 成员 | 作用 |
| --- | --- | --- |
| `IVisionModule` | `string Name`、`string Version`、`void Configure(string json)`、`string ExportConfig()` | 所有业务模块的统一形态；App 按此发现与挂载模块 |

## 2. Visual.IO（帧源采集）

只负责"稳定拿到带序号的帧"，不做任何图像处理。

### 2.1 契约

| 接口 | 成员 | 作用 |
| --- | --- | --- |
| `IFrameSource` | `string SourceId`、`int Width / Height`、`double Fps`、`bool IsRunning` | 帧源描述与状态 |
| | `event EventHandler<FramePacket> FrameReady` | 新帧到达（含帧号/时间戳） |
| | `event EventHandler<VisionException> SourceFailed` | 掉线/解码失败上报，不抛出崩溃 |
| | `Task OpenAsync(CancellationToken)` / `StartAsync(CancellationToken)` / `Task StopAsync()` / `Task CloseAsync()` | 生命周期：打开 → 采集 → 停止 → 释放 |

### 2.2 实现（internal，经工厂创建）

| 类 | 说明 |
| --- | --- |
| `UsbCameraSource` | OpenCV `VideoCapture` 直采 USB 摄像头；断线触发 `SourceFailed` 并可重连 |
| `VideoFileSource` | 本地视频文件；支持循环、暂停、单帧步进（调试/验收用） |
| `ImageFolderSource` | 按序读取图片文件夹（单元测试用，保证无摄像头可测） |
| `FrameSourceFactory` | `static IFrameSource CreateCamera(int deviceIndex)` / `CreateVideoFile(string path)` / `CreateImageFolder(string dir)`；外部唯二入口之一 |

## 3. Visual.VisionBase（视觉公共件）

纯函数式算子 + 检测/跟踪基类。无业务状态，不下业务结论。

### 3.1 预处理算子

| 类 | 方法 | 作用 |
| --- | --- | --- |
| `IPreprocessOperator` | `Mat Apply(Mat src)` | 算子统一接口 |
| `GrayscaleOp` | — | 灰度化 |
| `ThresholdOp` | 构造：`ThresholdOp(double threshold, bool useOtsu)` | 二值化 |
| `GaussianBlurOp` | 构造：核大小 | 滤波去噪 |
| `MorphologyOp` | 构造：`MorphologyOp(MorphTypes type, int kernelSize)` | 开/闭运算等形态学 |
| `CannyEdgeOp` | 构造：双阈值 | 边缘提取 |
| `PreprocessPipeline` | `Add(IPreprocessOperator)`、`Mat Run(Mat src)` | 算子组合管线，按添加顺序执行 |

### 3.2 分析算子

| 类 | 方法 | 作用 |
| --- | --- | --- |
| `BlobAnalyzer` | `IReadOnlyList<BlobInfo> Analyze(Mat binary)` | Blob/轮廓分析，输出面积、外接框、中心 |
| `BlobInfo`（DTO） | `Rect / Area / Center` | Blob 结果 |
| `TemplateMatcher` | `MatchResult Match(Mat src, Mat template)` | 模板匹配，输出位置与相似度 |
| `DifferenceDetector` | `IReadOnlyList<Rect> Compare(Mat reference, Mat current, double minArea)` | 差异对比（缺陷类基础算子，P1） |
| `StainDetector` / `ScratchDetector` | 输出疑似异常区域 + 面积 | 污点/划痕基础算子（P1；只给区域，不下 OK/NG） |

### 3.3 检测与跟踪基类

| 类 | 方法 | 作用 |
| --- | --- | --- |
| `TargetCandidate`（DTO） | `BoundingBox / Center / PixelSize / Confidence` | 几何层面的"找到了一个东西"，不含类别语义 |
| `TargetDetectorBase`（抽象） | `TargetCandidate? Detect(Mat frame, RoiRect roi)` | 在 ROI 内找目标；子类按算法实现 |
| `ContourTargetDetector` | — | 轮廓法实现（本期默认） |
| `TemplateTargetDetector` / `ColorTargetDetector` | — | 模板/颜色特征实现（可替换，FR-01-05） |
| `ITracker` | `void Init(Mat frame, Rect initial)`、`Rect? Update(Mat frame)`（丢失返回 null） | 相邻帧目标跟踪 |
| `OpenCvTracker` | 构造传入 OpenCV Tracker 类型（KCF/CSRT） | `ITracker` 的 OpenCV 封装 |

### 3.4 几何工具

| 类 | 方法 | 作用 |
| --- | --- | --- |
| `GeometryUtils` | `static double PixelToPhysical(double pixels, double scale)`、`static Point2D CenterOf(Rect)` | 像素↔物理量换算、几何计算 |
| `RoiExtensions` | `ClampTo(this RoiRect, int w, int h)` 等 | ROI 越界收敛（Abstractions 方法的算子化封装） |

## 4. Visual.Distance（测距模块）

本期唯一业务模块 = VisionBase 算子组合 + 标定状态 + mm 结论输出。

### 4.1 Contracts（对外）

| 类型 | 成员 | 作用 |
| --- | --- | --- |
| `IDistanceService : IVisionModule` | `bool IsCalibrated` | 标定状态查询 |
| | `void SetCalibration(CalibrationInfo info)` | 写入标定参数（模块持有状态） |
| | `Task<IReadOnlyList<DistanceMeasurement>> MeasureAsync(Mat frame, IReadOnlyList<RoiRect> rois, CancellationToken ct = default)` | 单帧测距：每个 ROI 一条结果 |
| | `IObservable<IReadOnlyList<DistanceMeasurement>> Observe(IFrameSource source, IReadOnlyList<RoiRect> rois)` | 实时模式：订阅式连续测量（FR-01-06） |
| | `void Configure(string json)` / `string ExportConfig()` | 配置导入导出（含标定，FR-01-01） |
| `DistanceServiceBuilder` | `WithDetector(TargetDetectorBase)`、`WithTracker(ITracker)`、`Build() : IDistanceService` | 构建入口；不指定则用默认实现（FR-01-05 算法可换） |
| `DistanceMeasurement : VisionResultBase` | `string TargetId`、`double? Distance`、`DistanceUnit Unit`、`Point2D? TargetCenter`、`double? TargetPixelSize` | 单目标测距结果；未检出/未标定时 `Distance = null` |
| `CalibrationInfo` | `RealWidth`、`PixelWidth`、`ReferenceDistance`、`DistanceUnit Unit` | 标定输入（参照物真实尺寸 + 像素尺寸 + 拍摄距离） |
| `NotCalibratedException : VisionException` | `ErrorCode = ModuleSpecific + 1` | 未标定调用测距时抛出（FR-01-04） |

### 4.2 Internal（实现，不对外）

| 类 | 职责 |
| --- | --- |
| `DistanceServiceImpl` | `IDistanceService` 实现：持有 `CalibrationInfo`、检测器、跟踪器；逐目标执行"检测/跟踪 → 换算 → 组结果"；连续 N 帧未检出置信度降 0（FR-01-09） |
| `MonocularCalibrator` | 由 `CalibrationInfo` 计算换算参数 `ScaleParams`（焦距等效系数），标定算法的唯一出口，未来可换双目/深度 |
| `DistanceConverter` | `double Estimate(double pixelSize, ScaleParams scale, DistanceUnit unit)`：像素尺寸 → 物理距离 |
| `RoiTargetTracker` | 每个 ROI 一个跟踪会话：首帧检测初始化、后续帧跟踪、丢失回退重新检测 |

## 5. Visual.AppCore（软件内部，不对外分发）

WPF 耦合，承载交互与编排。

| 类 | 方法/职责 |
| --- | --- |
| `RoiInteractionController` | 鼠标事件 → `RoiRect`：拖拽绘制、移动、缩放、清除；面积 < 16×16 拒绝（FR-03-02） |
| `OverlayRenderer` | `WriteableBitmap Render(Mat frame, IReadOnlyList<DistanceMeasurement> results)`：目标框/中心点/距离文本叠加，未检出置灰（FR-03-04） |
| `AppSettingsService` | 标定参数与界面配置读写本地 JSON；启动时经 `Configure(json)` 回灌模块（FR-03-03） |
| `ModuleCatalog` | 扫描已注册 `IVisionModule`，生成菜单项（FR-03-05 挂载入口） |

## 6. Visual.App（WPF 主程序）

| 类 | 职责 |
| --- | --- |
| `App.xaml.cs` | DI 容器构建：注册 `IFrameSource`、`IDistanceService`、各 ViewModel |
| `MainViewModel` | 视频源选择、播放控制、状态栏（未启动/未标定/未检出/测量中） |
| `DistanceViewModel` | 订阅 `Observe(...)` 实时刷新画面；调用 `RoiInteractionController` 圈选 |
| `CalibrationViewModel` | 标定表单 → `SetCalibration`；数值 > 0 校验 |
| Views | `MainWindow`、`DistanceView`、`CalibrationDialog`（MahApps.Metro + MaterialDesign） |
