# 04 — 目标检测与标定算法

| 项目 | 内容 |
| --- | --- |
| 文档版本 | V1.0 |
| 对应需求 | [01-需求规格说明书](./01-需求规格说明书.md) V4.3 |
| 适用范围 | 本期单相机、单目标 UI、单目视尺寸测距；公共 API 保留多 ROI 能力 |

## 1. 算法边界

本期测量的是**真实宽度已知的目标，与相机之间的近似轴向距离**。算法使用目标在图像中的像素宽度随距离变化的关系，不是双目、结构光、ToF 或任意物体三维重建。

前提条件：

- 相机位置、分辨率、焦距、对焦状态和数字缩放固定；
- 被测目标的真实测量宽度已知；
- 标定和运行时使用同一个测量轴；
- 目标测量面与成像面大致平行，不发生严重透视变形；
- 目标位于经过验证的测距范围内；
- 标定和测量使用同一检测配置及同一类目标。

不满足上述条件时，结果必须标记为失败或要求重新标定，不能继续输出看似有效的距离。

## 2. 本期默认目标定义

本期每个 ROI 约定最多存在一个有效目标。默认目标是 ROI 中经过分割后满足面积、宽高比、边界和置信度条件的最佳连通区域。

### 2.1 检测配置

`DetectionProfile` 定义在 `Visual.Vision.Contracts`，不得定义在 Distance 或 OpenCV 工程中。各引擎适配器读取同一契约并映射到自身实现。

```text
DetectionProfile
├─ ProfileId                 配置稳定标识
├─ ThresholdMode             Otsu / Manual
├─ ManualThreshold           手动阈值模式下使用，0~255
├─ ForegroundPolarity        Bright / Dark
├─ BlurKernelSize            3 或 5，必须为正奇数
├─ MorphologyKernelSize      形态学核大小
├─ MinAreaRatio              候选面积 / ROI 面积下限
├─ MaxAreaRatio              候选面积 / ROI 面积上限
├─ MinAspectRatio            最小宽高比
├─ MaxAspectRatio            最大宽高比
├─ BorderMargin              候选距离 ROI 边界的最小像素数
├─ MinimumConfidence         最低置信度
├─ MeasureAxis               Horizontal / Vertical / MajorAxis / MinorAxis
└─ RedetectInterval          跟踪期间强制重新检测的帧间隔
```

所有参数在开始处理一帧时生成不可变快照；同一帧处理中不得读取被 UI 修改一半的配置。

建议的首个默认 Profile：Otsu、亮前景、5×5 高斯滤波、3×3 形态学核、面积比例 0.01~0.90、宽高比 0.1~10、边界余量 2 px、最低置信度 0.5、水平测量轴、每 10 帧强制重检。所有值均可由宿主配置覆盖，并必须随测试数据记录。

### 2.2 默认检测流程

```text
ROI 视图
  → 转灰度
  → 高斯滤波
  → Otsu 或手动阈值分割
  → 按前景极性取前景
  → 形态学开/闭运算去噪
  → 查找外轮廓/连通区域
  → 面积、宽高比、边界条件过滤
  → 候选评分
  → 输出最佳 TargetCandidate
```

正常 ROI 流程只能创建视图，不复制整帧。格式转换产生的新缓冲必须带独立租约。

### 2.3 候选选择

候选评分至少包含：

- 面积是否处于配置范围；
- 宽高比是否处于配置范围；
- 是否接触 ROI 边界；
- 与上一帧中心位置的距离；
- 检测器自身置信度。

选择规则：

1. 没有历史目标时，选择合法候选中面积最大的一个；
2. 有历史目标时，优先选择中心点距离历史位置最近且尺寸变化合理的候选；
3. 得分低于 `MinimumConfidence` 时返回 `NotDetected`；
4. 多个候选得分相同时选择面积较大的候选；
5. 候选接触 ROI 边界时降低置信度；无法得到完整尺寸时拒绝测距。

`TargetPixelSize` 必须按照 `MeasureAxis` 计算。标定和运行时必须使用同一轴，禁止标定时用水平宽度、运行时改用最长边。

### 2.4 跟踪与重新检测

- 第一帧必须检测；
- 检测成功后可以初始化跟踪器；
- 每隔 `RedetectInterval` 帧强制重新检测；
- 跟踪失败、置信度过低、尺寸突变或目标越界时立即重新检测；
- 重新检测仍失败时返回 `NotDetected`，不得继续沿用过期框；
- 跟踪只优化连续帧性能，不改变检测结果的业务语义。

模板匹配为 P1；污点、划痕和缺陷差异不属于本期测距 P0 实现。未来 DNN/ONNX 检测器作为 `ITargetDetector` 的引擎适配实现接入，不放进 `Visual.Distance`。

## 3. 标定模型

### 3.1 符号

| 符号 | 含义 |
| --- | --- |
| `W` | 目标真实测量宽度 |
| `Z0` | 标定时目标与相机的已知距离 |
| `P0` | 标定时检测到的目标像素宽度 |
| `F` | 由标定得到的像素焦距系数 |
| `P` | 运行时检测到的目标像素宽度 |
| `Z` | 运行时估算距离 |

### 3.2 公式

标定：

```text
F = P0 × Z0 / W
```

运行时：

```text
Z = F × W / P
```

标定对象与被测对象真实宽度相同时可化简为：

```text
Z = Z0 × P0 / P
```

`W`、`Z0` 和 `Z` 必须使用同一物理单位。`P0 <= 0` 或 `P <= 0` 时禁止计算。

### 3.3 CalibrationInfo

```text
CalibrationInfo
├─ TargetPhysicalWidth       目标真实测量宽度
├─ ReferencePixelWidth       多帧有效样本的像素宽度中位数
├─ ReferenceDistance         标定距离
├─ Unit                      Mm / Cm / M
├─ MeasureAxis               像素尺寸测量轴
├─ CameraId                  相机标识
├─ ImageSize                 标定分辨率
├─ DetectionProfileId        检测配置标识
├─ ValidDistanceRange        已验证的最小/最大距离
├─ DistortionCorrected       是否经过镜头畸变校正
└─ SchemaVersion             配置结构版本
```

### 3.4 标定流程

1. 固定相机、分辨率、焦距、对焦和数字缩放；
2. 将已知真实宽度的目标放在已知距离 `Z0`；
3. 使用与运行时相同的 ROI、检测配置和测量轴；
4. 连续采集 10~30 帧；
5. 排除未检出、低置信度、触边和尺寸异常样本；
6. 对剩余像素宽度取中位数，得到 `P0`；
7. 生成标定参数；
8. 在近、中、远三个已知距离点各测量至少 10 次；
9. 平均绝对百分比误差满足需求后才允许保存并激活标定。

标定失败不得覆盖当前有效标定；新标定必须完整校验后原子替换。

### 3.5 标定失效条件

以下任一变化都会使当前标定无效：

- CameraId 改变；
- 分辨率、裁剪区域、焦距、对焦或数字缩放改变；
- `MeasureAxis` 改变；
- `DetectionProfileId` 或检测算法版本不兼容；
- 目标真实宽度改变；
- 配置 schema 不兼容；
- 目标距离超出已验证范围。

## 4. 单帧处理顺序

```text
校验帧与 TargetRegion
  → 校验标定快照和相机/分辨率
  → 为每个 ROI 创建 ImageView
  → 检测或跟踪 TargetCandidate
  → 读取指定测量轴的 TargetPixelSize
  → 按标定公式计算距离
  → 生成带状态、错误码、帧号和时间的 DistanceMeasurement
```

每个输入 `TargetRegion` 必须产生且只产生一条结果，结果顺序与输入顺序一致，并通过 `TargetId` 建立稳定映射。

本期一个 `IDistanceService` 实例使用一份活动标定，因此同一次多 ROI 请求约定目标具有相同的真实测量宽度和检测 Profile。未来若需同时测量不同尺寸/类别的目标，应在 `TargetRegion` 中增加 `CalibrationId` 或为不同目标使用独立服务实例，不能隐式套用同一标定。

## 5. 结果状态

| 状态 | 条件 |
| --- | --- |
| Valid | 输入、标定、检测和计算均有效 |
| NotDetected | ROI 合法，但没有满足条件的目标 |
| NotCalibrated | 实时流尚无有效标定或标定已失效 |
| Unavailable | 检测能力、相机或引擎当前不可用 |
| Failed | 算法或适配器发生已收敛的处理错误 |

参数非法、TargetId 重复、帧结构错误属于调用错误，单帧 API 抛 `VisionException(InvalidInput)`；它们不应伪装成 `NotDetected`。

## 6. 已知限制

- 单目视尺寸法不能可靠测量真实尺寸未知的任意物体；
- 目标旋转、倾斜、遮挡和镜头畸变会影响像素宽度；
- 自动对焦、数码变焦和分辨率变化会破坏标定；
- 单点标定只在验证过的距离范围内有效；
- 对精度要求高于当前 ±10% 时，应增加多点拟合、完整相机内参/畸变标定，或改用双目、结构光、ToF 等硬件。
