## 设计边界

- `Visual.Abstractions`、`Visual.Image`、`Visual.Vision.Contracts` 不引用任何视觉 SDK；
- `Visual.Distance` 不引用 OpenCV、HALCON、VisionPro 等具体引擎；
- `Visual.Engine.*` 是引擎适配器，原生 SDK 类型只允许出现在对应适配器内部；
- 当前只实现 `Visual.Engine.OpenCv`，HALCON 和 VisionPro 只保留接入位置，不提前创建空实现；
- 图像帧由创建方负责释放。跨异步调用前必须明确帧是否复制或是否延长生命周期；实时流默认“最新帧优先”，不等待旧帧。

## 2. Visual.Image

定义与引擎无关的图像帧和生命周期。

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `PixelFormat` | `Gray8 / Bgr24 / Bgra32 / Rgb24` | 支持的像素格式 |
| `ImageFrame` | `FrameInfo Info`、`PixelFormat Format`、`int Stride`、`ReadOnlyMemory<byte> Data` | 不可变 CPU 图像视图；自身不归还池内存，禁止跨租约使用 |
| `ImageFrameFactory` | `Rent(width, height, format)`、`FromExternal(...)`、`Clone(ImageFrame)` | 返回 `IImageLease`；从池租用、包装外部缓冲或按需复制，默认不复制 |
| `IImageLease` | `ImageFrame Frame`、`bool IsReleased`、`Retain()`、`Dispose()` | 唯一帧所有权对象；释放后归还池内存，多消费者必须成对 Retain/Dispose |
| `ImageMemoryPool` | `Rent(size)`、`Return(buffer)`、`GetStatistics()` | 基于 `MemoryPool<byte>`/`ArrayPool<byte>` 管理高频帧缓冲 |
| `ImageView` | `IImageLease OwnerLease`、`Offset`、`Width`、`Height`、`Stride`、`Crop(RoiRect)` | ROI 视图，不复制原始整帧；不得超过所有者租约生命周期，需独立生命周期时创建新租约 |
| `FrameBuffer` | `Capacity`、`TryWrite(IImageLease)`、`TryReadLatest()`（返回租约）、`DroppedCount`、`Complete()` | 有界最新帧缓冲；队列持有租约，满时释放并丢弃旧帧，不允许无限堆积 |

OpenCV 的 `Mat`、HALCON 的 `HObject`、VisionPro 的 `CogImage` 只能在引擎适配器内部与 `ImageFrame` 转换。适配器应优先包装外部内存或使用 SDK 的引用视图；只有 SDK 生命周期不允许时才复制。

### 2.1 图像处理规则

1. 采集端从 `ImageMemoryPool` 租用一块缓冲，写入一帧后创建租约；
2. `FrameBuffer` 只保留有限数量的租约，默认容量为 3；新帧到达时优先丢弃未被消费者持有的旧帧；
3. ROI 使用 `ImageView`，不复制整帧；
4. 引擎适配器需要的格式转换才创建新缓冲，转换结果也必须有租约；
5. 检测完成后按引用计数释放所有租约，归还池内存；
6. UI 不持有采集帧，只持有截图或标准结果，并按固定频率刷新；
7. 长时间运行测试必须检查 `DroppedCount`、池使用量、托管内存和原生内存。

## 3. Visual.IO

定义帧源与设备生命周期契约，并提供不绑定具体 SDK 的缓冲和幂等生命周期基类。

本层不实现 OpenCV、HALCON 或 VisionPro 的采集逻辑；采集实现属于对应的 `Visual.Engine.*`，本层只提供统一帧源接口。

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `IFrameSource` | `SourceId`、`Width`、`Height`、`Fps`、`IsRunning`、`DroppedCount` | 统一帧源契约和丢帧统计 |
|  | `ReadFramesAsync(CancellationToken)` | 以 `IAsyncEnumerable<IImageLease>` 输出帧；实现内部使用有界缓冲 |
|  | `OpenAsync`、`StartAsync`、`StopAsync`、`CloseAsync`、`DisposeAsync` | 帧源生命周期，停止和释放幂等 |
| `FrameSourceState` | `Closed / Opened / Running / Reconnecting / Failed` | 帧源结构化状态 |
| `IFrameSourceFactory` | `Create(descriptor)` | 按配置创建帧源；具体实现由引擎适配器提供 |
| `BufferedFrameSourceBase` | `TryPublishFrame`、有界缓冲、取消、fatal error 和幂等启停 | 引擎帧源复用的 SDK 无关生命周期骨架；成功发布后接管租约，失败时所有权仍归调用方 |
| `CameraDescriptor` | `Id`、`Name`、`Vendor`、`Model`、`Capabilities` | 相机设备描述 |
| `CameraCapabilities` | `Resolutions`、`FrameRates`、`Exposure`、`Gain`、`Focus` | 相机能力清单 |
| `ICameraDeviceProvider` | `EnumerateAsync`、`OpenAsync(descriptor)` | 设备发现和创建，具体实现位于引擎适配器 |
| `ICameraDevice` | `ConnectAsync`、`DisconnectAsync`、`GetCapabilitiesAsync`、`SetParameterAsync` | 单个设备的连接、能力和参数操作 |
| `CameraDeviceBase` | 幂等连接/断开、能力和参数校验、异常收敛 | 引擎设备实现复用的 SDK 无关生命周期骨架 |

## 4. Visual.Vision.Contracts

定义业务模块需要的视觉能力，不包含具体 SDK 类型。

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `IPreprocessOperator` | `IImageLease Apply(ImageFrame source)` | 预处理算子接口；输入只借用，输出租约由调用方释放，禁止返回无所有权的裸新帧 |
| `ITargetDetector` | `TargetCandidate? Detect(ImageFrame frame, RoiRect roi)` | 目标检测接口 |
| `ITracker : IDisposable` | `Initialize(ImageFrame, RoiRect)`、`Update(ImageFrame)`、`Dispose()` | 目标跟踪接口；创建方负责释放跨帧跟踪状态和原生资源 |
| `TargetCandidate` | `BoundingBox`、`Center`、`PixelSize`、`Confidence` | 通用目标结果 |
| `PixelMeasureAxis` | `Horizontal / Vertical / MajorAxis / MinorAxis` | 标定与检测统一使用的像素尺寸测量轴 |
| `DetectionProfile` | 阈值模式、前景极性、滤波/形态学、面积/宽高比、边界、置信度、测量轴、重检间隔 | 引擎无关的检测配置；引擎适配器读取并转换为自身实现参数 |
| `VisionEngineInfo` | `Id`、`Name`、`Version`、`IsAvailable`、`LicenseState`、`Capabilities` | 引擎状态和能力 |
| `VisionCapability` | `Preprocess / Detection / Tracking / Camera / IntrinsicCalibration / ThreeD` | 引擎能力枚举；业务测距不作为引擎能力 |
| `IVisionEngine` | `Info`、`CreateDetector`、`CreateTracker`、`CreatePreprocessor` | 引擎统一入口 |
| `IVisionEngineProvider` | `GetAvailableEngines()`、`Get(id)` | 引擎发现和选择 |

## 5. Visual.VisionBase

引擎无关的公共流程、几何计算、结果整理和判定辅助类。具体图像算法实现放到引擎适配器中。

本层不负责灰度、轮廓、模板等 SDK 算法实现，只负责对这些能力进行组合、校验和结果整理。

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `RoiValidator` | `Validate`、`Clamp` | ROI 合法性检查 |
| `GeometryUtils` | `CenterOf`、`PixelToPhysical` | 通用几何计算 |
| `DetectionPipeline` | 单跟踪器与 `IReadOnlyList<ITracker?>` 两组 `Run` 重载 | ROI 与跟踪器按索引对齐；跟踪有效时复用，否则回退检测并重新初始化跟踪器 |
| `PreprocessPipeline` | `Add`、`Run` | 组合多个 `IPreprocessOperator`；流水线释放中间租约，最终租约交给调用方 |
| `MeasurementResultFactory` | `CreateNotDetected`、`CreateSuccess`、`CreateFailed` | 统一结果构造 |
| `VisionEngineSelector` | `Select`、`CheckCapability` | 检查引擎是否可用、能力是否满足 |
| `IFrameProcessor` | `ProcessAsync` | 运行时的单帧处理边界；处理期间只借用帧 |
| `VisionRuntime` | `StartAsync`、`StopAsync`、`CancelCurrentWork`、`Completion` | 管理帧源、处理循环、租约释放和停止顺序 |
| `VisionDiagnostics` | `RuntimeStarted`、`RuntimeStopped`、`FrameProcessed`、`FrameDropped`、`EngineFailed`、`ConfigurationRejected` | 有界保存结构化诊断，并隔离外部诊断接收器故障 |

OpenCV 的灰度、二值化、滤波、轮廓和缺陷区域算法属于 `Visual.Engine.OpenCv` 的实现；通用接口属于 `Visual.Vision.Contracts`，公共流程属于本层。

## 6. Visual.Engine.OpenCv

当前唯一实现的视觉引擎适配器。该工程可以引用 OpenCvSharp，但不得被 `Visual.Distance` 引用。

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `OpenCvEngine` | `Info`、`CreateDetector`、`CreateTracker`、`CreatePreprocessor` | 实现 `IVisionEngine` |
| `OpenCvEngineProvider` | `GetAvailableEngines`、`Get` | 检测 OpenCV runtime 是否可用 |
| `OpenCvDeviceProvider` | `EnumerateAsync`、`OpenAsync` | 枚举 OpenCV 可见设备并创建统一设备对象；单个设备沿用 `ICameraDevice` 生命周期 |
| `OpenCvFrameSourceFactory` | `Create(FrameSourceDescriptor)` | 按 Camera、VideoFile、ImageFolder 描述创建帧源并校验选项 |
| `OpenCvImageAdapter`（internal） | `ToMat(ImageFrame)`、`FromMat(Mat, FrameInfo)` | 借用输入时固定内存并零复制包装；OpenCV 输出复制到独立 `IImageLease` |
| `OpenCvCameraSource` | `OpenAsync`、`StartAsync`、`StopAsync`、`CloseAsync` | 使用 OpenCV 采集相机帧 |
| `OpenCvVideoFileSource` | `OpenAsync`、`StartAsync`、`PauseAsync`、`StepAsync`、`LoopPlayback` | 使用 OpenCV 解码本地视频；可选在同一解码器内循环，默认到文件尾结束 |
| `OpenCvImageFolderSource` | `StartAsync`、`StepAsync` | 使用 OpenCV 解码测试图片序列 |
| `OpenCvGrayscaleOperator` | `Apply(ImageFrame)` | 灰度化 |
| `OpenCvThresholdOperator` | `Apply(ImageFrame)` | 二值化 |
| `OpenCvBlurOperator` | `Apply(ImageFrame)` | 滤波去噪 |
| `OpenCvMorphologyOperator` | `Apply(ImageFrame)` | 形态学处理 |
| `OpenCvEdgeOperator` | `Apply(ImageFrame)` | 边缘提取 |
| `OpenCvBlobDetector` | `Detect(ImageFrame, RoiRect)` | 轮廓/Blob 目标检测 |
| `OpenCvTemplateDetector` | `Detect(ImageFrame, RoiRect)` | 模板匹配检测 |
| `OpenCvTracker` | `Initialize`、`Update` | 基于模板的基础连续帧跟踪；低置信度失败并按 `RedetectInterval` 强制回退检测 |
| `OpenCvDifferenceDetector` | `Compare` | 差异区域检测 |
| `OpenCvStainDetector` / `OpenCvScratchDetector` | `Detect` | 污点/划痕区域检测，不下业务结论 |

本期 P0 只实现灰度、滤波、阈值、形态学、轮廓/Blob 和一个基础跟踪器；模板匹配为 P1，差异、污点和划痕类型仅记录未来适配位置，不进入当前 M4 完成定义。

M4 已实现表中的 P0 类型及三类帧源。`OpenCvTemplateDetector`、`OpenCvDifferenceDetector`、`OpenCvStainDetector` 和 `OpenCvScratchDetector` 仍只是未来设计位置，没有创建占位实现。

## 7. Visual.Engine.Halcon / Visual.Engine.VisionPro

当前不实现具体代码，只保留适配器边界。

未来每个适配器至少包含：

| 类型 | 作用 |
| --- | --- |
| `HalconEngine` / `VisionProEngine` | 实现 `IVisionEngine` |
| `HalconImageAdapter` / `VisionProImageAdapter` | 原生图像对象与 `ImageFrame` 转换 |
| `HalconEngineProvider` / `VisionProEngineProvider` | SDK、许可证、版本和能力检测 |
| 具体 Detector/Tracker/Operator | 将厂商 SDK 工具转换为公共接口 |

适配器缺少 SDK 或许可证时，返回 `EngineUnavailable` / `LicenseInvalid`，不能影响其他引擎启动。

## 8. Visual.Distance

本期业务模块。它依赖 `Visual.Abstractions`、`Visual.Image`、`Visual.IO`、`Visual.Vision.Contracts` 和 `Visual.VisionBase`，不依赖任何具体引擎。

### 8.1 Contracts

| 类型 | 方法/成员 | 作用 |
| --- | --- | --- |
| `IDistanceService : IVisionModule, IAsyncDisposable` | `IsCalibrated`、`SetCalibration`、`DisposeAsync` | 标定状态和标定参数；释放服务拥有的跨帧跟踪器 |
|  | `MeasureAsync(DistanceRequest, CancellationToken)` | 单帧测距，每个 TargetRegion 一条结果；借用帧但不释放调用方租约 |
|  | `MeasureStreamAsync(IFrameSource, IReadOnlyList<TargetRegion>, CancellationToken)` | 以 `IAsyncEnumerable` 输出实时测距结果 |
| `DistanceServiceBuilder` | `WithEngine(IVisionEngine)`、`WithDetector(ITargetDetector)`、`WithDetectionProfile(DetectionProfile)`、`Build()` | 显式 Detector 优先；否则由 Engine 按 Profile 创建；两者均无或能力不足时 Build 失败 |
| `TargetRegion` | `TargetId`、`Bounds` | 输入目标标识和 ROI；同一请求内 TargetId 唯一 |
| `DistanceRequest` | `Frame`、`Targets` | 单帧测距请求；配置和标定由服务在帧开始时读取不可变快照 |
| `DistanceMeasurement : VisionResultBase` | `TargetId`、`Distance`、`Unit`、`TargetBounds`、`TargetCenter`、`TargetPixelSize` | 带状态、错误码、目标几何、帧号和时间信息的标准测距结果 |
| `CalibrationInfo` | `TargetPhysicalWidth`、`ReferencePixelWidth`、`ReferenceDistance`、`Unit`、`MeasureAxis`、`CameraId`、`ImageSize`、`DetectionProfileId`、`ValidDistanceRange`、`SchemaVersion` | 完整标定快照 |
| `DistanceRange` | `Minimum`、`Maximum`、`Contains` | 标定验证过的距离范围；范围外不输出有效距离 |
| `NotCalibratedException` | `VisionErrorCode` | 未标定错误 |

### 8.2 Internal

| 类型 | 作用 |
| --- | --- |
| `DistanceServiceImpl` | 组合检测、跟踪、标定和换算，输出标准结果；管理实时流启停，但不释放调用方帧源，也不保存处理完成后的图像帧 |
| `DistanceResultBuilder` | 提供 `Valid`、`NotDetected`、`NotCalibrated`、`Unavailable`、`Failed` 构建入口，生成带状态和错误码的标准测距结果 |
| `MonocularCalibrator` | 根据标定输入生成换算参数 |
| `DistanceConverter` | 像素尺寸转换为物理距离 |
| `RoiTargetTracker` | 管理 ROI 对应的检测和跟踪状态 |
