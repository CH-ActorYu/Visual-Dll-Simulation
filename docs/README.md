# Visual 视觉软件 — 文档中心

本目录统一存放项目文档。

> **产品定位**：一款视觉功能软件（WPF），业务功能以**独立模块 DLL** 形式组织——每个模块可单独拆出，被其他项目（如 HardwareModularWorkflow）直接引用。本期功能：**实时目标测距**，后续按模块增量扩展。

## 分层交付物速查

| 层 | DLL | 职责 | 独立交付 |
| --- | --- | --- | --- |
| 基础契约 | Visual.Abstractions | 通用值对象 / 结果基类 / 异常 / 模块入口 | ✅（随模块分发） |
| IO 采集 | Visual.IO | `IFrameSource`：摄像头 / 视频文件 / 图片序列取帧 | ✅（可单独分发） |
| 视觉基础 | Visual.VisionBase | 预处理 / 分析算子、检测跟踪基类、几何换算 | ✅（随模块分发） |
| 业务模块 | Visual.Distance（本期） | 实时目标测距 | ✅（核心交付物） |
| 软件层 | Visual.App / AppCore | WPF 界面、ROI 交互、叠加渲染 | ❌（WPF 耦合） |

细分判断标准与"不再细分"清单（标定不拆、算子不拆等）见 SRS §4.3~§4.4；基础与业务的归类判定见 SRS §4.5。

## 模块 DLL 规范要点（详见 SRS §3.1）

- 纯 `net10.0` 类库，禁止引用 UI 框架；
- 对外仅暴露 Contracts（接口 + DTO + 异常），实现 `internal`；
- 依赖仅限共享层 + OpenCvSharp4 + BCL；参数由调用方传入；
- 语义化版本；配套无 UI 测试与 ConsoleDemo。
