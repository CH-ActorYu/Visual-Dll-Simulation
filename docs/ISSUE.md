# 问题记录（ISSUE）

## 记录规范

- 每行一个问题，编号递增（I-001、I-002……），**不删除已关闭的问题**；
- 状态：`🔴 待处理` / `🔨 处理中` / `✅ 已解决` / `⏸ 挂起`；
- 严重度：`P0 阻塞开发` / `P1 影响功能` / `P2 体验或边缘情况`；
- 解决后必须填写"原因"与"解决方案"，并注明关联提交号；
- 新会话接手时，先扫一眼 `🔴/🔨` 状态的问题再开工。
