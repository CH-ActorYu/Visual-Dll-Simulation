# M7.2 S8 稳定性验收记录（第 2 次）

## 1. 条件与修正

第 2 次使用单个 `OpenCvVideoFileSource(loopPlayback: true)` 连续循环同一 720p 视频，并以固定大小直方图统计处理耗时，已排除第 1 次的高频解码器重开和无界列表增长。

| 字段 | 内容 |
| --- | --- |
| 日期/执行人 | 2026-07-19 / Codex 自动化执行 |
| 被测提交 | `415fb5a` + `8a2da06` |
| 构建 | Release x64，无调试器 |
| 时长 | 预热 30 秒，正式统计 7200.05 秒，每 10 秒采样 |
| 报告 SHA-256 | `7BD19E6FC687E3DE1F5313ADF1D8B267D9E723B8F5012BD24FE84DF2196267BB` |

## 2. 结果

| 指标 | 结果 | 验收线 |

| 正式统计帧 | 152,683 | 记录项 |

曲线在 10～70 分钟主要稳定于约 126 MB，结束阶段稳定于约 130～132 MB；719 个采样区间中有 341 次上升，也有大量回落，不是持续单调增长。尽管如此，按预热 30 秒后的首样本计算仍超过验收线。

## 3. 结论

**S8 第 2 次 Fail**：第 1 次的运行器偏差已排除，但进程内存首末增长仍超过 10%。

## 4. 后续诊断

720p BGR24 单帧约 2.64 MB。第 2 次后段出现队列高水位时，Private Bytes 阶跃增加约 4～5 MB，符合 `ArrayPool` 首次缓存额外帧数组的量级。仅凭进程 Private Bytes 无法证明租约泄漏，因此增加以下可观测性：

- `OpenCvFrameSourceBase.MemoryPoolStatistics`；
- 每个资源采样记录 `TotalRented`、`TotalReturned`、`Outstanding`、`PeakOutstanding`；
- 稳定性预热阶段主动触发一次完整缓冲高水位，使正式基线包含设计容量；
- S8 通过条件额外要求结束时 `Outstanding == 0` 且 `TotalRented == TotalReturned`。

修正后的 60 秒验证达到 `PeakOutstanding=4`，正式采样期间 `Outstanding=0`，停止后 `Rented=Returned=1455`，Private Bytes 增长 2.88%。仍需第 3 次完整两小时测试才能签认。
